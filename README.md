# unicampus_laf

Campus Lost & Found Management System

A web-based application designed to help university students report lost items, register found belongings, and reconnect items with their rightful owners.

built by Abdurezak Anwar, Fullstack developer, CTC-2844-26.

## Overview

Users can submit reports with item descriptions, photos, dates, and locations. They can browse, search, and filter reports, submit claims, and track the status of recovered items.

The platform includes:
- lost item reporting
- found item registration
- search and filtering
- claim submission and verification
- ownership verification workflow
- recovery status tracking
- audit logs for important actions
- administrator moderation and claim management dashboard

## Tech Stack

- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: PostgreSQL
- Version control: Git + GitHub
- Authentication: email/password, with Google sign-in planned later

## Project Goal

To provide a reliable, user-friendly system for university communities to recover lost belongings quickly while maintaining transparency, accountability and trust.
