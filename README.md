# unicampus_laf

Campus Lost & Found Management System

A web-based platform designed to help university students report lost items, register found belongings, and reconnect possessions with their rightful owners.

Built by: Abdurezak Anwar.
Role in project: Fullstack Developer.
INSA ID: CTC-2844-26.

---

## Overview

Users can submit reports with item descriptions, photos, dates, and locations. They can browse, search, and filter reports, submit claims, and track the progress of recovered items.

This system is built to support a smooth and transparent recovery process for the university community.

### Core Features

- Lost item reporting
- Found item registration
- Search and filtering
- Claim submission and verification
- Ownership verification workflow
- Recovery status tracking
- Audit logs for important actions
- Administrator moderation and claim management dashboard

---

## Tech Stack

- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: PostgreSQL
- Version control: Git + GitHub
- Authentication: Email/password, with Google sign-in planned later

---

## Project Goal

To provide a reliable, user-friendly system for university communities to recover lost belongings quickly while maintaining transparency, accountability, and trust.

---

## Why It Matters

Lost and found processes often become inefficient, confusing, and difficult to track. This platform aims to simplify that experience by making item reporting, verification, and recovery more organized and accessible.
